MacClaw setup

Mac 上部署 sshd + tailscaled

这份脚本面向中国网络环境：不依赖 Homebrew，使用国内 Go 镜像和 Go module 代理，启用 macOS SSH，并把 tailscaled 安装为系统 daemon，重启后不登录桌面也会启动。

复制后粘贴到 macOS Terminal 执行 
bash <<'MACCLAW_SCRIPT'
set -euo pipefail

# ===== 可选：如果这台 Mac 有代理，填这里；没有就保持注释 =====
# export http_proxy=http://127.0.0.1:7890
# export https_proxy=http://127.0.0.1:7890
# export all_proxy=socks5://127.0.0.1:7890

GO_VER="1.25.11"

log() { printf '\n==> %s\n' "$*"; }

if [[ "$(uname -s)" != "Darwin" ]]; then
  echo "This script is for macOS only."
  exit 1
fi

ARCH="$(uname -m)"
case "$ARCH" in
  arm64) GOARCH="arm64" ;;
  x86_64) GOARCH="amd64" ;;
  *) echo "Unsupported Mac arch: $ARCH"; exit 1 ;;
esac

GO_PKG="go${GO_VER}.darwin-${GOARCH}.pkg"

log "Enable macOS SSH server"
sudo systemsetup -setremotelogin on
sudo launchctl enable system/com.openssh.sshd 2>/dev/null || true
sudo launchctl kickstart -k system/com.openssh.sshd 2>/dev/null || true
systemsetup -getremotelogin || true

log "Install Go ${GO_VER} from China mirrors if missing"
if ! command -v go >/dev/null 2>&1; then
  OK=0
  for MIRROR in \
    "https://mirrors.aliyun.com/golang" \
    "https://mirrors.ustc.edu.cn/golang" \
    "https://mirrors.nju.edu.cn/golang" \
    "https://mirrors.hust.edu.cn/golang"
  do
    URL="${MIRROR}/${GO_PKG}"
    echo "Trying: $URL"
    if curl -fL --retry 3 --connect-timeout 15 -o "/tmp/${GO_PKG}" "$URL"; then
      OK=1
      break
    fi
  done

  if [[ "$OK" != "1" ]]; then
    echo "Failed to download ${GO_PKG} from China mirrors."
    exit 1
  fi

  sudo installer -pkg "/tmp/${GO_PKG}" -target /
fi

export PATH="/usr/local/go/bin:$HOME/go/bin:/usr/local/bin:$PATH"

log "Go version"
go version

log "Set China-friendly Go module proxy"
go env -w GOPROXY=https://goproxy.cn,https://goproxy.io,direct

log "Build tailscale and tailscaled"
if ! CGO_ENABLED=0 go install tailscale.com/cmd/tailscale@latest tailscale.com/cmd/tailscaled@latest; then
  echo "First go install failed. Retrying with GOSUMDB=off for China network fallback..."
  go env -w GOSUMDB=off
  CGO_ENABLED=0 go install tailscale.com/cmd/tailscale@latest tailscale.com/cmd/tailscaled@latest
fi

log "Install binaries to /usr/local/bin"
sudo mkdir -p /usr/local/bin
sudo install -m 0755 "$HOME/go/bin/tailscale" /usr/local/bin/tailscale
sudo install -m 0755 "$HOME/go/bin/tailscaled" /usr/local/bin/tailscaled

log "Install tailscaled as macOS system daemon"
sudo /usr/local/bin/tailscaled install-system-daemon

log "Start / restart tailscaled daemon"
if [[ -f /Library/LaunchDaemons/com.tailscale.tailscaled.plist ]]; then
  sudo launchctl bootstrap system /Library/LaunchDaemons/com.tailscale.tailscaled.plist 2>/dev/null || true
fi
sudo launchctl kickstart -k system/com.tailscale.tailscaled
sleep 2

log "Verify tailscaled daemon"
sudo launchctl print system/com.tailscale.tailscaled >/dev/null

log "Tailscale login / bring up"
echo "If a login URL appears below, open it in browser and finish login."
sudo /usr/local/bin/tailscale up

log "Tailscale status"
sudo /usr/local/bin/tailscale status || true

log "Tailscale IPv4"
sudo /usr/local/bin/tailscale ip -4 || true

log "Verify SSH"
systemsetup -getremotelogin || true

cat <<'DONE'

DONE.
- macOS sshd has been enabled.
- tailscaled has been installed as a system daemon.
- After reboot, tailscaled should start before user login.

Useful checks:
  sudo launchctl print system/com.tailscale.tailscaled
  sudo tailscale status
  sudo tailscale ip -4
  sudo systemsetup -getremotelogin

DONE
MACCLAW_SCRIPT

执行方式

点 Copy，把脚本粘贴到 Terminal。脚本会自动交给 bash 执行，避免 zsh 的 ! 历史展开问题。中途会要 Mac 密码；如果出现 Tailscale 登录链接，打开后完成登录。

网络说明

  • Go 安装包优先走阿里云、中科大、南大、华科镜像。
  • Go module 走 goproxy.cn 和 goproxy.io。
  • Tailscale 登录和中继仍可能受当前网络影响。

重启行为

这里安装的是 CLI-only tailscaled system daemon，不是菜单栏 App。Mac 重启后，它应在用户登录前由 launchd 拉起。
