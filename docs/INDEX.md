## 9. Ongoing rule

From here, the low-risk default is:

1. Keep the repository root minimal.
2. Put all new general documentation under `docs/`.
3. Prefer topic folders over adding new root-level markdown files.
4. Move older files only when there is a clear navigation benefit.

This keeps the repository browsable without creating unnecessary churn.
